# Drip Check Studio

## ▶ [Open the live app](https://i4mshanks.github.io/DripCheck/)

A streetwear wardrobe studio with a 360° 3D mannequin. It has a digital closet, a garment scanner and a curated lookbook.

## Run it locally

```bash
npm install
npm run dev   # http://localhost:3000
```

## Deploying

Every push to `main` builds the app and publishes it to GitHub Pages using `.github/workflows/deploy.yml`.
